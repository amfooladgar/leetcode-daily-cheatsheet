# assets/

- `contact-card.png` — already in place (your LeetCode visit card). Swap it
  for a different image anytime by overwriting this file — no code change
  needed. See docs/SETUP.md step 4 for size/format notes if you replace it.
  If this file is ever missing, the renderer logs a warning and produces the
  cheat sheet without a contact card overlay rather than failing.
- `fonts/` — bundled DejaVu fonts used for deterministic rendering (see
  ARCHITECTURE.md "Why no AI image model" and `assets/fonts/LICENSE-DEJAVU.txt`
  for the redistribution license). Do not delete these.
